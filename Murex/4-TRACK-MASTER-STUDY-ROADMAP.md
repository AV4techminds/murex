# 4-TRACK MASTER STUDY ROADMAP

## Tracks

1. **Python** — programming, automation, XML/JSON, Oracle, APIs, testing and clean coding.
2. **Unix/Linux + Shell + Networking** — commands, processes, permissions, logs, scripting, SSH/SFTP, TCP/IP, DNS, HTTP/HTTPS and troubleshooting.
3. **Murex Techno-Functional** — capital markets, trade lifecycle, Murex architecture, static/market data, risk, P&L, settlement and accounting.
4. **Murex Integration + Datamart** — XML/MXML, interfaces, SFTP, APIs, messaging, batch, Oracle/SQL, Datamart, reporting and reconciliation.

## Core Method

**Learn → Note → Practice → Integrate → Troubleshoot → Explain → Review**

A topic is complete only when:
- [ ] I can define it simply
- [ ] I understand its business purpose
- [ ] I understand where it fits technically
- [ ] I have a practical example
- [ ] I practiced it where applicable
- [ ] I know common failures
- [ ] I can explain basic troubleshooting
- [ ] I can answer interview questions
- [ ] Notes and glossary are updated
- [ ] Git commit is done

Commands/concept + shell/network exercise + troubleshooting.

### Block 4 — Integration/Datamart (30–45 min)
XML/MXML/API/SFTP/SQL/Datamart concept tied to the Murex topic.

### Block 5 — Interview Review (10–15 min)
Answer aloud:
1. What is it?
2. Why is it needed?
3. How does it work?
4. Where can it fail?
5. How would I troubleshoot it?

# GOLDEN RULES

1. Do not rush through the syllabus.
2. Understand business flow before memorizing terminology.
3. Write Python every study day.
4. Practice Linux commands instead of only reading them.
5. Practice networking through troubleshooting.
6. Practice SQL against real/sample data.
7. Design interfaces instead of memorizing interface terms.
8. Connect Datamart back to source data.
9. Do not tick a topic until you can explain it.
10. Review old topics every week.
11. Keep one Git repository as the long-term record.
12. Build progressively larger labs.
13. Practice production incidents.
14. Explain answers aloud.
15. Keep improving the final project.
